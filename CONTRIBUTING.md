# Руководство по внесению вклада

Спасибо, что рассматриваете возможность внести вклад в проект! Участвуя, вы соглашаетесь соблюдать [кодекс поведения](CODE_OF_CONDUCT.md).

## Как внести вклад

1. Сделайте форк репозитория и склонируйте его на локальную машину
2. Создайте новую ветку: `git checkout -b feature/название`
3. Внесите изменения и закоммитьте: `git commit -am 'Описание изменений'`
4. Отправьте изменения: `git push origin feature/название`
5. Создайте Pull Request в ветку `main`
6. Откликайтесь на отзывы в ходе код-ревью

## Стиль кода

- Следуйте рекомендациям [PEP8](https://pep8.org/)
- Используйте осмысленные имена переменных и функций
- Документируйте код там, где это необходимо

## Сообщение об ошибках

Создайте [Issue на GitHub](https://github.com/ZephronixQ/noc-monitor/issues) с описанием проблемы и шагами для её воспроизведения.

Благодарю за участие в проекте!
