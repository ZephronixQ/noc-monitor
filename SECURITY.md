## Реализованные механизмы защиты

В версии v5.0.0 встроена комплексная система защиты информации enterprise-уровня:

1. **Авторизация и JWT-токены:** 
   - Аутентификация операторов интегрирована с Django Auth.
   - Все эндпоинты API `/api/*` и WebSocket `/ws` защищены авторизационными заголовками `Authorization: Bearer <token>`.
   - Токены подписываются алгоритмом HMAC-SHA256 с использованием серверного `DJANGO_SECRET_KEY`. Срок действия сессии фиксируется на 365 дней.
2. **Централизованное управление правами (RBAC):**
   - Управление учётными записями, правами доступа (`is_staff`, `is_superuser`) и отзыв доступа операторов осуществляется централизованно через Django Admin (`/admin/`).
3. **Изоляция сетевого контура:**
   - Серверный стек работает в изолированной внутренней сети Docker (`internal bridge`).
   - Доступ снаружи открыт исключительно через Nginx Reverse Proxy (порт 80/443), предотвращая прямой доступ к портам ASGI и базам данных.
4. **Защита от анализа кода на клиенте (`security.js`):**
   - Блокировка контекстного меню (`contextmenu`).
   - Блокировка вызова консоли разработчика и инспектора кода (`F12`, `Ctrl+Shift+I`, `Ctrl+Shift+J`, `Ctrl+U`, `Ctrl+S`).
   - Активный цикл задержки отладки (`debugger`).
